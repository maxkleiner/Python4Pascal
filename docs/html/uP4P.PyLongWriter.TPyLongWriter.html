Public function Finish: IPyObject;

Finish a PyLongWriter created by TPyLongWriter.Create().

On success, return a Python int object. On error, set an exception and return nil.

The function takes care of normalizing the digits and converts the object to a compact integer if needed.

The writer instance and the digits array are invalid after the call.

Public class function New(negative: boolean; ndigits: Py_ssize_t; var digits: Pointer): IPyLongWriter;

Create a PyLongWriter.

On success, allocate *digits and return a writer. On error, set an exception and return nil.

negative is True if the number is negative, or False otherwise.

ndigits is the number of digits in the digits array. It must be greater than 0.

digits must not be nil.

After a successful call to this function, the caller should fill in the array of digits digits and then call TPyLongWriter.Finish() to get a Python int. The layout of digits is described by TPyLong.GetNativeLayout().

Digits must be in the range [0; (1 << bits_per_digit) - 1] (where the bits_per_digit is the number of bits per digit). Any unused most significant digits must be set to 0.

Alternately, call TPyLongWriter.Discard() to destroy the writer instance without creating an int object.
