Methods

Public class function Check(const aPyObject: IPyObject): boolean;

Return true if od is an ordered dictionary object or an instance of a subtype of the OrderedDict type. This function always succeeds.

Public class function CheckExact(const aPyObject: IPyObject): boolean;

Return true if od is an ordered dictionary object, but not an instance of a subtype of the OrderedDict type. This function always succeeds.

Public class function New: IPyObject;

Return a new empty ordered dictionary, or nil on failure.

This is analogous to TPyDict,New().

Public class function SetItem(const od, key, value: IPyObject): boolean;

Insert value into the ordered dictionary od with a key of key. Return True on success or False with an exception set on failure.

This is analogous to TPyDict.SetItem().

Public class function DelItem(const od, key: IPyObject): boolean;

Remove the entry in the ordered dictionary od with key key. Return True on success or False with an exception set on failure.

This is analogous to TPyDict.DelItem().
