type TPyBool = class(TObject)

Description

Helper class for all PyBool_* methods. Booleans in Python are implemented as a subclass of integers. There are only two booleans, Py_False and Py_True. As such, the normal creation and deletion functions don't apply to booleans.

<see href="https://docs.python.org/3/c-api/bool.html#boolean-objects">See the article about Boolean Objects.)
