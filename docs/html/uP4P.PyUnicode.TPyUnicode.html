Public class function Resize(const unicode: IPyObject; length_: Py_ssize_t): boolean;

Resize a Unicode object *unicode to the new length in code points.

Try to resize the string in place (which is usually faster than allocating a new string and copying characters), or create a new string.

*unicode is modified to point to the new (resized) object and True is returned on success. Otherwise, False is returned and an exception is set, and *unicode is left untouched.

The function doesn't check string content, the result may not be a string in canonical representation.

Public class function FromEncodedObject(const obj: IPyObject; const encodging, errors: PAnsiChar): IPyObject;

Decode an encoded object obj to a Unicode object.

bytes, bytearray and other bytes-like objects are decoded according to the given encoding and using the error handling defined by errors. Both can be nil to have the interface use the default values (see Built-in Codecs for details).

All other objects, including Unicode objects, cause a TypeError to be set.

The API returns nil if there was an error. The caller is responsible for decref'ing the returned objects.

Public class procedure InternInPlace(const p_unicode: IPyObject);

Intern the argument *p_unicode in place. The argument must be a Python Unicode string object. If there is an existing interned string that is the same as *p_unicode, it sets *p_unicode to it (releasing the reference to the old string object and creating a new strong reference to the interned string object), otherwise it leaves *p_unicode alone and interns it.

(Clarification: even though there is a lot of talk about references, think of this function as reference-neutral. You must own the object you pass in; after the call you no longer own the passed-in reference, but you newly own the result.)

This function never raises an exception. On error, it leaves its argument unchanged without interning it.

Instances of subclasses of str may not be interned, that is, TPyUnicode.CheckExact(*p_unicode) must be true. If it is not, then - as with any other error - the argument is left unchanged.

Note that interned strings are not "immortal". You must keep a reference to the result to benefit from interning.

Public class function InternFromString(const str: string): IPyObject;

A combination of TPyUnicode.FromString() and TPyUnicode.InternInPlace(), meant for statically allocated strings.

Return a new ("owned") reference to either a new Unicode string object that has been interned, or an earlier interned string object with the same value.

Python may keep a reference to the result, or make it immortal, preventing it from being garbage-collected promptly. For interning an unbounded number of different strings, such as ones coming from user input, prefer calling TPyUnicode.FromString() and TPyUnicode.InternInPlace() directly.

Public class function FromWideChar(const w: PWCharT; size_: Py_ssize_t): IPyObject;

Create a Unicode object from the wchar_t buffer wstr of the given size. Passing -1 as the size indicates that the function must itself compute the length, using wcslen(). Return nil on failure.

Public class function AsWideChar(const unicode: IPyObject; w: PWCharT; size_: Py_ssize_t): Py_ssize_t;

Copy the Unicode object contents into the wchar_t buffer wstr. At most size wchar_t characters are copied (excluding a possibly trailing nil termination character). Return the number of wchar_t characters copied or -1 in case of an error.

When wstr is nil, instead return the size that would be required to store all of unicode including a terminating nil.

Note that the resulting wchar_t* string may or may not be nil-terminated. It is the responsibility of the caller to make sure that the wchar_t* string is nil-terminated in case this is required by the application. Also, note that the wchar_t* string might contain nil characters, which would cause the string to be truncated when used with most C functions.

Public class function AsWideCharString(const unicode: IPyObject; var size_: Py_ssize_t): PWCharT;

Convert the Unicode object to a wide character string. The output string always ends with a nil character. If size is not nil, write the number of wide characters (excluding the trailing nil termination character) into *size. Note that the resulting wchar_t string might contain nil characters, which would cause the string to be truncated when used with most C functions. If size is nil and the wchar_t* string contains nil characters a ValueError is raised.

Returns a buffer allocated by TPyMem.New (use TPyMem.Free() to free it) on success. On error, returns nil and *size is undefined. Raises a MemoryError if memory allocation is failed.

Public class function AsUTF8AndSize(const unicode: IPyObject; var size_: Py_ssize_t): PAnsiChar;

Return a pointer to the UTF-8 encoding of the Unicode object, and store the size of the encoded representation (in bytes) in size. The size argument can be nil; in this case no size will be stored. The returned buffer always has an extra nil byte appended (not included in size), regardless of whether there are any other nil code points.

On error, set an exception, set size to -1 (if it's not nil) and return nil.

The function fails if the string contains surrogate code points (U+D800 - U+DFFF).

This caches the UTF-8 representation of the string in the Unicode object, and subsequent calls will return a pointer to the same buffer. The caller is not responsible for deallocating the buffer. The buffer is deallocated and pointers to it become invalid when the Unicode object is garbage collected.

Public class function DecodeUTF32(const str: PAnsiChar; length: Py_ssize_t; errors: TPyCodecErrors; var byteorder: TPyBiteOrder): IPyObject;

Decode size bytes from a UTF-32 encoded buffer string and return the corresponding Unicode object. errors (if non-nil) defines the error handling. It defaults to "strict".

If byteorder is non-nil, the decoder starts decoding using the given byte order: 

*byteorder == -1: little endian
*byteorder == 0:  native order
*byteorder == 1:  big endian

If *byteorder is zero, and the first four bytes of the input data are a byte order mark (BOM), the decoder switches to this byte order and the BOM is not copied into the resulting Unicode string. If *byteorder is -1 or 1, any byte order mark is copied to the output.

After completion, *byteorder is set to the current byte order at the end of input data.

If byteorder is nil, the codec starts in native order mode.

Return nil if an exception was raised by the codec.

Public class function DecodeUTF32Stateful(const str: PAnsiChar; length: Py_ssize_t; errors: TPyCodecErrors; var byteorder: TPyBiteOrder; var consumed: Py_ssize_t): IPyObject;

If consumed is nil, behave like TPyUnicode.DecodeUTF32(). If consumed is not nil, TPyUnicode.DecodeUTF32Stateful() will not treat trailing incomplete UTF-32 byte sequences (such as a number of bytes not divisible by four) as an error. Those bytes will not be decoded and the number of bytes that have been decoded will be stored in consumed.

Public class function AsUTF32String(const unicode: IPyObject): IPyObject;

Return a Python byte string using the UTF-32 encoding in native byte order. The string always starts with a BOM mark. Error handling is "strict". Return nil if an exception was raised by the codec.

Public class function DecodeUTF16(const str: PAnsiChar; length: Py_ssize_t; errors: TPyCodecErrors; var byteorder: TPyBiteOrder): IPyObject;

Decode size bytes from a UTF-16 encoded buffer string and return the corresponding Unicode object. errors (if non-nil) defines the error handling. It defaults to "strict".

If byteorder is non-nil, the decoder starts decoding using the given byte order: 

*byteorder == -1: little endian
*byteorder == 0:  native order
*byteorder == 1:  big endian

If *byteorder is zero, and the first two bytes of the input data are a byte order mark (BOM), the decoder switches to this byte order and the BOM is not copied into the resulting Unicode string. If *byteorder is -1 or 1, any byte order mark is copied to the output (where it will result in either a \ufeff or a \ufffe character).

After completion, *byteorder is set to the current byte order at the end of input data.

If byteorder is nil, the codec starts in native order mode.

Return nil if an exception was raised by the codec.

Public class function DecodeUTF16Stateful(const str: PAnsiChar; length: Py_ssize_t; errors: TPyCodecErrors; var byteorder: TPyBiteOrder; var consumed: Py_ssize_t): IPyObject;

If consumed is nil, behave like TPyUnicode.DecodeUTF16(). If consumed is not nil, TPyUnicode.DecodeUTF16Stateful() will not treat trailing incomplete UTF-16 byte sequences (such as an odd number of bytes or a split surrogate pair) as an error. Those bytes will not be decoded and the number of bytes that have been decoded will be stored in consumed.

Public class function AsUTF16String(const unicode: IPyObject): IPyObject;

Public class function DecodeCharmap(const str: PAnsiChar; length: Py_ssize_t; const mapping: IPyObject; errors: TPyCodecErrors): IPyObject;

Create a Unicode object by decoding size bytes of the encoded string str using the given mapping object. Return nil if an exception was raised by the codec.

If mapping is nil, Latin-1 decoding will be applied. Else mapping must map bytes ordinals (integers in the range from 0 to 255) to Unicode strings, integers (which are then interpreted as Unicode ordinals) or None. Unmapped data bytes - ones which cause a LookupError, as well as ones which get mapped to None, $FFFE or '\ufffe', are treated as undefined mappings and cause an error.

Public class function AsCharmapString(const unicode, mapping: IPyObject): IPyObject;

Encode a Unicode object using the given mapping object and return the result as a bytes object. Error handling is "strict". Return nil if an exception was raised by the codec.

The mapping object must map Unicode ordinal integers to bytes objects, integers in the range from 0 to 255 or None. Unmapped character ordinals (ones which cause a LookupError) as well as mapped to None are treated as "undefined mapping" and cause an error.

Public class function New(size_: Py_ssize_t; maxchar: Py_UCS4): IPyObject;

Create a new Unicode object. maxchar should be the true maximum code point to be placed in the string. As an approximation, it can be rounded up to the nearest value in the sequence 127, 255, 65535, 1114111.

On error, set an exception and return nil.

After creation, the string can be filled by TPyUnicode.WriteChar(), TPyUnicode.CopyCharacters(), TPyUnicode.Fill(), TPyUnicode.WRITE() or similar. Since strings are supposed to be immutable, take care to not "use" the result while it is being modified. In particular, before it's filled with its final contents, a string: 

- must not be hashed,
- must not be converted to UTF-8, or another non-"canonical" representation,
- must not have its reference count changed,
- must not be shared with code that might do one of the above.

This list is not exhaustive. Avoiding these uses is your responsibility; Python does not always check these requirements.

To avoid accidentally exposing a partially-written string object, prefer using the PyUnicodeWriter API, or one of the TPyUnicode.From* functions.
