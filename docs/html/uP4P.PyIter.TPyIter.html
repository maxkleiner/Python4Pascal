Methods

Public class function Check(const o: IPyObject): boolean;

Return True if the object o provides the AsyncIterator protocol, and False otherwise. This function always succeeds.

Public class function NextItem(const iter: IPyObject; out item: IPyObject): integer;

Return 1 and set item to a strong reference of the next value of the iterator iter on success. Return 0 and set item to nil if there are no remaining values. Return -1, set item to nil and set an exception on error.

Added in version 3.14.

Public class function Next(const iter: IPyObject): IPyObject;

This is an older version of TPyIter.NextItem(), which is retained for backwards compatibility.

Prefer TPyIter.NextItem().

Return the next value from the iterator iter. The object must be an iterator according to TPyIter.Check() (it is up to the caller to check this). If there are no remaining values, returns nil with no exception set. If an error occurs while retrieving the item, returns nil and passes along the exception.

Public class function Send(const iter, arg: IPyObject; out presult: IPyObject): PySendResult;

Sends the arg value into the iterator iter. Returns: 

- PYGEN_RETURN if iterator returns. Return value is returned via
  presult.
- PYGEN_NEXT if iterator yields. Yielded value is returned via
  presult.
- PYGEN_ERROR if iterator has raised and exception. presult is set to
  nil.
