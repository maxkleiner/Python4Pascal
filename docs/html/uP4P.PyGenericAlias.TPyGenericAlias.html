Public class function New(const origin, args: IPyObject): IPyObject;

Create a GenericAlias object. Equivalent to calling the Python class types.GenericAlias. The origin and args arguments set the GenericAlias's __origin__ and __args__ attributes respectively. origin should be a PyTypeObject*, and args can be a PyTupleObject* or any PyObject*. If args passed is not a tuple, a 1-tuple is automatically constructed and __args__ is set to (args,). Minimal checking is done for the arguments, so the function will succeed even if origin is not a type. The GenericAlias's __parameters__ attribute is constructed lazily from __args__.

Public class function Check(const aPyObject: IPyObject): boolean;

Return True if the aPyObject's type is GenericAlias or a subtype of GenericAlias.
