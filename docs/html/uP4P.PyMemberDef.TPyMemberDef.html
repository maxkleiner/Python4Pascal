uP4P.PyMemberDef

Declaration

type TPyMemberDef = class(TObject)

Description

Class that describes an attribute of a type which corresponds to a C struct member. When defining a class, put a nil-terminated array of these structures in the tp_members slot.

<see href="https://docs.python.org/3/c-api/structures.html#c.PyMemberDef">See the article about PyMemberDef.)

Properties

Public property Name_ : AnsiString read GetName write SetName;

Name of the member. A nil value marks the end of a PyMemberDef[] array. The string should be static, no copy is made of it.

Public property Type_ : integer read GetType write SetType;

The type of the member in the C struct. See Member types for the possible values.

Public property Offset : Py_ssize_t read GetOffset write SetOffset;

The offset in bytes that the member is located on the type's object struct.

Public property Flags : integer read GetFlags write SetFlags;

Zero or more of the Member flags, combined using bitwise OR.

Public property Doc : AnsiString read GetDoc write SetDoc;

The docstring, or nil. The string should be static, no copy is made of it. Typically, it is defined using PyDoc_STR.

Public property MemberDef : PyMemberDef read GetMemberDef;

Return the PyMemberDef record.

Public property IsSentinel : boolean read GetIsSentinel;

Return True if all the PyMemberDef fields are nil or empty.
