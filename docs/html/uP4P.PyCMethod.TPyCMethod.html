Public class function Check(const aPyObject: IPyObject): boolean;

Return true if op is an instance of the PyCMethod_Type type or a subtype of it. This function always succeeds.

Public class function CheckExact(const aPyObject: IPyObject): boolean;

This is the same as TPyCMethod.Check(), but does not account for subtypes.

Public class function New(const ml: PyMethodDef; const self_, module: IPyObject; const cls: PyTypeObject): IPyObject;

Turn ml into a Python callable object. The caller must ensure that ml outlives the callable. Typically, ml is defined as a static variable.

The self_ parameter will be passed as the self_ argument to the function in ml->ml_meth when invoked. self_ can be nil.

The callable object's __module__ attribute can be set from the given module argument. module should be a Python string, which will be used as name of the module the function is defined in. If unavailable, it can be set to None or nil.

See also function.__module__

The cls parameter will be passed as the defining_class argument to the C function. Must be set if METH_METHOD is set on ml->ml_flags.
