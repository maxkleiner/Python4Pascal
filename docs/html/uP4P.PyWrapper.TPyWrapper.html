Public class function New(const d, self_: IPyObject): IPyObject;

Create a new bound wrapper object from the wrapper descriptor d and the instance self_.

This is the bound form of a wrapper descriptor created by TPyDescr.NewWrapper(). CPython creates these objects when a slot wrapper is accessed through an instance, and they appear in Python as types.MethodWrapperType objects.

On success, return a strong reference to the wrapper object. Return nil with an exception set on failure.
