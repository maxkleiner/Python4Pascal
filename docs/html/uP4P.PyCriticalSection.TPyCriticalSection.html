Declaration

type TPyCriticalSection = class(TInterfacedObject, IPyCriticalSection)

Description

A critical section protected by one mutex. You *CANNOT* use nested critical sections to lock more than one object at once.

<see href="https://docs.python.org/3/c-api/synchronization.html#python-critical-section-api">See the Python critical section API article.)
