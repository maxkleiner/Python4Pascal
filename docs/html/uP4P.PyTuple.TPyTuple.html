Public class function Size(const p: IPyObject): Py_ssize_t;

Take a pointer to a tuple object, and return the size of that tuple. On error, return -1 with an exception set.

Public class function GetItem(const p: IPyObject; pos: Py_ssize_t): IPyObject; overload;

Return the object at position pos in the tuple pointed to by p. If pos is negative or out of bounds, return nil and set an IndexError exception.

The returned reference is borrowed from the tuple p (that is: it is only valid as long as you hold a reference to p). To get a strong reference, use TPy.NewRef(TPyTuple.GetItem(...)) or TPySequence.GetItem().

Public class function SetItem(const p: IPyObject; pos: Py_ssize_t; const o: IPyObject): boolean; overload;

Insert a reference to object o at position pos of the tuple pointed to by p. Return True on success. If pos is out of bounds, return False and set an IndexError exception.

Note: This function "steals" a reference to o and discards a reference to an item already in the tuple at the affected position (unless it was nil).

Public class function GetSlice(const p: IPyObject; low, high: Py_ssize_t): IPyObject;

Return the slice of the tuple pointed to by p between low and high, or nil with an exception set on failure.

This is the equivalent of the Python expression p[low:high]. Indexing from the end of the tuple is not supported.

Public class function New(len: Py_ssize_t): IPyObject;

Return a new tuple object of size len, or nil with an exception set on failure.

Public class function Pack(const objects: IPyObjectArray): IPyObject;

Return a new tuple object of size n, or nil with an exception set on failure. The tuple values are initialized to the subsequent n arguments pointing to Python objects. TPyTuple.Pack(2, a, b) is equivalent to TPy.BuildValue("(OO)", a, b).
