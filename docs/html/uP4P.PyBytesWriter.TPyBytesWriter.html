Declaration

type TPyBytesWriter = class(TInterfacedObject, IPyBytesWriter)

Description

A bytes writer instance.

The PyBytesWriter API can be used to create a Python bytes object.

The API is not thread safe: a writer should only be used by a single thread at the same time.

<see href="https://docs.python.org/3.15/c-api/bytes.html#pybyteswriter">See the article about PyBytesWriter.)

Added in version 3.15.

Public class function Create(size_: Py_ssize_t): IPyBytesWriter; overload;

Create a PyBytesWriter to write size bytes.

If size is greater than zero, allocate size bytes, and set the writer size to size. The caller is responsible to write size bytes using TPyBytesWriter.GetData(). This function does not overallocate.

On error, set an exception and return nil.

size must be positive or zero.

Public function Finish: IPyObject;

Finish a PyBytesWriter created by TPyBytesWriter.Create().

On success, return a Python bytes object. On error, set an exception and return nil.

The writer instance is invalid after the call in any case.

No API can be called on the writer after TPyBytesWriter.Finish().

Public function FinishWithSize(size_: Py_ssize_t): IPyObject;

Similar to TPyBytesWriter.Finish(), but resize the writer to size bytes before creating the bytes object.

Public function FinishWithPointer(buf: Pointer): IPyObject;

Similar to TPyBytesWriter.Finish(), but resize the writer using buf pointer before creating the bytes object.

Set an exception and return nil if buf pointer is outside the internal buffer bounds.

Function pseudo-code: 

Py_ssize_t size = (char*)buf - (char*)PyBytesWriter_GetData(writer);
return PyBytesWriter_FinishWithSize(writer, size);

Public function WriteBytes(const bytes_: Pointer; size_: Py_ssize_t): boolean; overload;

Grow the writer internal buffer by size_ bytes, write size_ bytes of bytes_ at the writer end, and add size_ to the writer size.

If size is equal to -1, call strlen(bytes) to get the string length.

On success, return True. On error, set an exception and return False.

Public function WriteBytes(const aStream: TMemoryStream): boolean; overload;

Grow the writer internal buffer by aStreamsize.size bytes, write aStream.size bytes at the writer end, and add aStreamsize.size to the writer size.

On success, return True. On error, set an exception and return False.

Public function Resize(size_: Py_ssize_t): boolean;

Resize the writer to size bytes. It can be used to enlarge or to shrink the writer. This function typically overallocates to achieve amortized performance when resizing multiple times.

Newly allocated bytes are left uninitialized.

On success, return True. On error, set an exception and return False.

size must be positive or zero.

Public function Grow(size_: Py_ssize_t): boolean;

Resize the writer by adding grow bytes to the current writer size. This function typically overallocates to achieve amortized performance when resizing multiple times.

Newly allocated bytes are left uninitialized.

On success, return True. On error, set an exception and return False.

size can be negative to shrink the writer.

Public function GrowAndUpdatePointer(size_: Py_ssize_t; buf: Pointer): Pointer;

Similar to TPyBytesWriter.Grow(), but update also the buf pointer.

The buf pointer is moved if the internal buffer is moved in memory. The buf relative position within the internal buffer is left unchanged.

On error, set an exception and return nil.

buf must not be nil.

Function pseudo-code: 

Py_ssize_t pos = (char*)buf - (char*)PyBytesWriter_GetData(writer);
if (PyBytesWriter_Grow(writer, size) < 0) {
    return NULL;
}
return (char*)PyBytesWriter_GetData(writer) + pos;
