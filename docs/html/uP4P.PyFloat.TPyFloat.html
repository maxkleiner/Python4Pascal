Public class function AsDouble(const obj: IPyObject): double;

Return a double representation of the contents of pyfloat. If pyfloat is not a Python floating-point object but has a __float__() method, this method will first be called to convert pyfloat into a float. If __float__() is not defined then it falls back to __index__(). This method returns -1.0 upon failure, so one should call TPyErr.Occurred() to check for errors.
