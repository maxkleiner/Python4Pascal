Public class function Check(const o: IPyObject): boolean;

Return True if the object provides the sequence protocol, and False otherwise. Note that it returns True for Python classes with a __getitem__() method, unless they are dict subclasses, since in general it is impossible to determine what type of keys the class supports. This function always succeeds.

Returns the number of objects in sequence o on success, and -1 on failure. This is equivalent to the Python expression len(o).

Public class function SetItem(const o: IPyObject; i: Py_ssize_t; v: IPyObject): boolean; overload;

Assign object v to the ith element of o. Raise an exception and return False on failure; return True on success. This is the equivalent of the Python statement o[i] = v. This function does not "steal" a reference to v.

If v is nil, the element is deleted, but this feature is deprecated in favour of using TPySequence.DelItem().

Public class function Tuple(const o: IPyObject): IPyObject;

Return a tuple object with the same contents as the sequence or iterable o, or nil on failure. If o is a tuple, a new reference will be returned, otherwise a tuple will be constructed with the appropriate contents. This is equivalent to the Python expression tuple(o).

Public class function List(const o: IPyObject): IPyObject;

Return a list object with the same contents as the sequence or iterable o, or nil on failure. The returned list is guaranteed to be new. This is equivalent to the Python expression list(o).

Public class function Fast(const o: IPyObject; const m: string): IPyObject;

Return the sequence or iterable o as an object usable by the other TPySequence.Fast* family of functions. If the object is not a sequence or iterable, raises TypeError with m as the message text. Returns nil on failure.

The TPySequence.Fast* functions are thus named because they assume o is a PyTupleObject or a PyListObject and access the data fields of o directly.

As a CPython implementation detail, if o is already a sequence or list, it will be returned.

Public class function Count(const o, value: IPyObject): Py_ssize_t;

Return the number of occurrences of value in o, that is, return the number of keys for which o[key] == value. On failure, return -1. This is equivalent to the Python expression o.count(value).

Public class function Contains(const o, value: IPyObject): integer; overload;

Determine if o contains value. If an item in o is equal to value, return 1, otherwise return 0. On error, return -1. This is equivalent to the Python expression value in o.
