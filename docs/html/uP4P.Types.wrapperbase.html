type wrapperbase = record

Description

Describes a slot wrapper used by PyDescr_NewWrapper(). Each wrapperbase record stores the Python-visible name and metadata for a special method implemented by a type slot, together with the wrapper function used to adapt that slot to Python's calling convention.

<see href="https://docs.python.org/3/c-api/descriptor.html#c.wrapperbase">See the article about wrapperbase.)
