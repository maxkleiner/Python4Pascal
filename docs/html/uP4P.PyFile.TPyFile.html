Public class function FromFd(fd: integer; const mode: string; buffering: integer; const encoding, errors, newline: string; closefd: boolean): IPyObject;

Create a Python file object from the file descriptor of an already opened file fd. The arguments name, encoding, errors and newline can be nil to use the defaults; buffering can be -1 to use the default. name is ignored and kept for backward compatibility. Return nil on failure. For a more comprehensive description of the arguments, please refer to the io.open() function documentation.

Warning: Since Python streams have their own buffering layer, mixing them with OS-level file descriptors can produce various issues (such as unexpected ordering of data).

Public class function GetLine(const p: IPyObject; n: integer): IPyObject;

Equivalent to p.readline([n]), this function reads one line from the object p. p may be a file object or any object with a readline() method. If n is 0, exactly one line is read, regardless of the length of the line. If n is greater than 0, no more than n bytes will be read from the file; a partial line can be returned. In both cases, an empty string is returned if the end of the file is reached immediately. If n is less than 0, however, one line is read regardless of length, but EOFError is raised if the end of the file is reached immediately.

Public class function WriteObject(const obj, p: IPyObject; flags: integer): boolean;

Write object obj to file object p. The only supported flag for flags is Py_PRINT_RAW; if given, the str() of the object is written instead of the repr().

If obj is nil, write the string "<NULL>".

Return True on success or False on failure; the appropriate exception will be set.

Public class function WriteString(const s: string; const p: IPyObject): boolean;

Write string s to file object p. Return True on success or False on failure; the appropriate exception will be set.

Public class function NewStdPrinter(fd: integer): IPyObject;

Use TPyFile.FromFd() with defaults (fd, nil, 'w', -1, nil, nil, nil, 0) instead.

Public class function OpenCode(const path: string): IPyObject;

Similar to TPyFile.OpenCodeObject(), but path is a string.

Public class function OpenCodeObject(const path: IPyObject): IPyObject;

Open path with the mode 'rb'. path must be a Python str object. The behavior of this function may be overridden by TPyFile.SetOpenCodeHook() to allow for some preprocessing of the text.

This is analogous to io.open_code() in Python.

On success, this function returns a strong reference to a Python file object. On failure, this function returns nil with an exception set.

Public class function SetOpenCodeHook(handler: Py_OpenCodeHookFunction; userData: Pointer): boolean;

Overrides the normal behavior of io.open_code() to pass its parameter through the provided handler.

The handler is a function of type: 

typedef PyObject *(*Py_OpenCodeHookFunction)(PyObject*, void*)

Equivalent of PyObject *(*)(PyObject *path, void *userData), where path is guaranteed to be PyUnicodeObject.

The userData pointer is passed into the hook function. Since hook functions may be called from different runtimes, this pointer should not refer directly to Python state.

As this hook is intentionally used during import, avoid importing new modules during its execution unless they are known to be frozen or available in sys.modules.

Once a hook has been set, it cannot be removed or replaced, and later calls to TPyFile.SetOpenCodeHook() will fail. On failure, the function returns False and sets an exception if the interpreter has been initialized.

This function is safe to call before TPy.Initialize().

Raises an auditing event setopencodehook with no arguments.
