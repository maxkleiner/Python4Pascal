Methods

Public class function GetPointer(var view: Py_buffer; const indices: Py_ssize_t_array): Pointer;

Get the memory area pointed to by the indices inside the given view. indices must point to an array of view->ndim indices.

Public class function SizeFromFormat(const format: PAnsiChar): Py_ssize_t;

Return the implied itemsize from format. On error, raise an exception and return -1.

Public class function ToContiguous(buf: Pointer; var src: Py_buffer; len: Py_ssize_t; order: TPyBufferOrder): boolean;

Copy len bytes from src to its contiguous representation in buf. order can be 'C' or 'F' or 'A' (for C-style or Fortran-style ordering or either one). True is returned on success, False on error.

This function fails if len != src->len.

Public class function FromContiguous(var view: Py_buffer; const buf: Pointer; len: Py_ssize_t; fort: TPyBufferOrder): boolean;

Copy contiguous len bytes from buf to view. fort can be 'C' or 'F' (for C-style or Fortran-style ordering). True is returned on success, False on error.

Public class function IsContiguous(var view: Py_buffer; order: TPyBufferOrder): boolean;

Return True if the memory defined by the view is C-style (order is 'C') or Fortran-style (order is 'F') contiguous or either one (order is 'A'). Return False otherwise. This function always succeeds.

Public class procedure FillContiguousStrides(ndims: Integer; shape, strides: PPy_ssize_t; itemsize: Integer; order: TPyBufferOrder);

Fill the strides array with byte-strides of a contiguous (C-style if order is 'C' or Fortran-style if order is 'F') array of the given shape with the given number of bytes per element.

Public class function FillInfo(var view: Py_buffer; const exporter: IPyObject; buf: Pointer; len: Py_ssize_t; readonly, flags: Integer): boolean;

Handle buffer requests for an exporter that wants to expose buf of size len with writability set according to readonly. buf is interpreted as a sequence of unsigned bytes.

The flags argument indicates the request type. This function always fills in view as specified by flags, unless buf has been designated as read-only and PyBUF_WRITABLE is set in flags.

On success, set view->obj to a new reference to exporter and return True. Otherwise, raise BufferError, set view->obj to nil and return False;

If this function is used as part of a getbufferproc, exporter MUST be set to the exporting object and flags must be passed unmodified. Otherwise, exporter MUST be nil.

Public class procedure Release(var view: Py_buffer);

Release the buffer view and release the strong reference (i.e. decrement the reference count) to the view's supporting object, view->obj. This function MUST be called when the buffer is no longer being used, otherwise reference leaks may occur.

It is an error to call this function on a buffer that was not obtained via TPyObject.GetBuffer().
