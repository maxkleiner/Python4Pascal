Properties

Public property Config : Pointer read GetConfig;

Pointer to the PyPreConfig record.

Public property Initialized : boolean read GetInitialized;

Returns true if this class is fully initialized.

Public property parse_argv : boolean read Get_parse_argv write Set_parse_argv;

If True, TPy.PreInitializeFromArgs() and TPy.PreInitializeFromBytesArgs() parse their argv argument the same way the regular Python parses command line arguments: see Command Line Arguments.

Default: True in Python config, False in isolated config.

Public property isolated : boolean read Get_isolated write Set_isolated;

If True, enable isolated mode: 

- Set safe_path to True: don't prepend a potentially unsafe path to
  sys.path at Python startup, such as the current directory, the
  script's directory or an empty string.
- Set use_environment to False: ignore PYTHON environment variables.
- Set user_site_directory to False: don't add the user site directory
  to sys.path.
- Python REPL doesn't import readline nor enable default readline
  configuration on interactive prompts.

Set to True by the -I command line option.

Default: False in Python mode, True in isolated mode.

<see href="https://docs.python.org/3/c-api/init_config.html#isolated-configuration">See the article about Isolated Configuration.)

Public property use_environment : boolean read Get_use_environment write Set_use_environment;

Use environment variables?

If False, ignore the environment variables.

Set to False by the -E environment variable.

Default: True in Python config and False in isolated config.

<see href="https://docs.python.org/3/using/cmdline.html#using-on-envvars">See the article about environment variables.)

Public property configure_locale : boolean read Get_configure_locale write Set_configure_locale;

Set the LC_CTYPE locale to the user preferred locale.

If False, set coerce_c_locale and coerce_c_locale_warn members to False.

See the locale encoding.

Default: True in Python config, False in isolated config.

Public property coerce_c_locale : integer read Get_coerce_c_locale write Set_coerce_c_locale;

If equals to 2, coerce the C locale.

If equals to 1, read the LC_CTYPE locale to decide if it should be coerced.

See the locale encoding.

Default: -1 in Python config, 0 in isolated config.

Public property coerce_c_locale_warn : boolean read Get_coerce_c_locale_warn write Set_coerce_c_locale_warn;

If True, emit a warning if the C locale is coerced.

Default: True in Python config, False in isolated config.

Public property legacy_windows_fs_encoding : boolean read Get_legacy_windows_fs_encoding write Set_legacy_windows_fs_encoding;

If True: 

- Set PyPreConfig.utf8_mode to False,
- Set PyConfig.filesystem_encoding to "mbcs",
- Set PyConfig.filesystem_errors to "replace".

Initialized from the PYTHONLEGACYWINDOWSFSENCODING environment variable value. Only available on Windows.

Default: False.

Public property utf8_mode : integer read Get_utf8_mode write Set_utf8_mode;

If True, enable the Python UTF-8 Mode.

Set to False or True by the -X utf8 command line option and the PYTHONUTF8 environment variable.

Also set to True if the LC_CTYPE locale is C or POSIX.

Default: True in Python config and False in isolated config.

<see href="https://docs.python.org/3/using/cmdline.html#envvar-PYTHONUTF8">See the article about PYTHONUTF8.)

<see href="https://docs.python.org/3/library/os.html#utf8-mode">See the article about Python UTF-8 Mode.)

Public property dev_mode : boolean read Get_dev_mode write Set_dev_mode;

If True, enable the Python Development Mode.

Set to True by the -X dev option and the PYTHONDEVMODE environment variable.

Default: True in Python mode, False in isolated mode.

<see href="https://docs.python.org/3/library/devmode.html#devmode">See the article about Python Development Mode.)
