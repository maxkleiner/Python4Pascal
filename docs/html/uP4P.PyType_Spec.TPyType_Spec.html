Properties

Public property Name_ : AnsiString read GetName write SetName;

Name of the type, used to set PyTypeObject.tp_name.

Public property DocStrings : AnsiString read GetDocStrings write SetDocStrings;

The docstring for this type object. This is exposed as the __doc__ attribute on the type and instances of the type.

Public property Basicsize : integer read GetBasicsize write SetBasicsize;

If positive, specifies the size of the instance in bytes. It is used to set PyTypeObject.tp_basicsize.

If zero, specifies that tp_basicsize should be inherited.

If negative, the absolute value specifies how much space instances of the class need in addition to the superclass.

Use TPyObject.GetTypeData to get a pointer to subclass-specific memory reserved this way.

For negative basicsize, Python will insert padding when needed to meet tp_basicsize's alignment requirements.

Public property Itemsize : integer read GetItemsize write SetItemsize;

Size of one element of a variable-size type, in bytes. Used to set PyTypeObject.tp_itemsize. See tp_itemsize documentation for caveats.

Public property Flags : cardinal read GetFlags write SetFlags;

Type flags, used to set PyTypeObject.tp_flags.

Use the Py_TPFLAGS_* constants.

Public property HasSentinelSlot : boolean read GetHasSentinelSlot;

Return True if the last slot has a {0, nil} value.

Public property HasSentinelMethod : boolean read GetHasSentinelMethod;

Return True if the last method in the list is a sentinel method.

Public property HasSentinelMember : boolean read GetHasSentinelMember;

Return True if the last method in the list is a sentinel member.

Public property HasSentinelGetSet : boolean read GetHasSentinelGetSet;

Return True if the last method in the list is a sentinel getsetter.

Public property Slots : PPyType_Slot read GetSlots;

Return a pointer to the first slot.

Public property TypeSpec : PPyType_Spec read GetTypeSpec;

Return a pointer to the PyType_Spec record.

Public property Token : pointer read GetToken write SetToken;

The associated token records a static memory layout ID for a class.

Useg the special value Py_TP_USE_SPEC to set the token to the class's PyType_Spec.
