Methods

Public class function Check(const aPyObject: IPyObject): boolean;

Return True if aPyObject is a frame object.

Public class function New(tstate: PPyThreadState; const code, globals, locals: IPyObject): IPyObject;

Create a new frame object. This function returns a strong reference to the new frame object on success, and returns nil with an exception set on failure.

Public class function GetLineNumber(const frame: IPyObject): integer;

Return the line number that frame is currently executing.

Public class function GetCode(const frame: IPyObject): IPyObject;

Get the frame code. Return a strong reference.

The result (frame code) cannot be nil.

Public class function GetBack(const frame: IPyObject): IPyObject;

Get the frame next outer frame.

Return a strong reference, or nil if frame has no outer frame. This raises no exceptions.

Public class function GetLocals(const frame: IPyObject): IPyObject;

Get the frame's f_locals attribute. If the frame refers to an optimized scope, this returns a write-through proxy object that allows modifying the locals. In all other cases (classes, modules, exec(), eval()) it returns the mapping representing the frame locals directly (as described for locals()).

Return a strong reference.

Added in version 3.11.

Public class function GetGlobals(const frame: IPyObject): IPyObject;

Get the frame's f_globals attribute.

Return a strong reference. The result cannot be nil.

Added in version 3.11.

Public class function GetBuiltins(const frame: IPyObject): IPyObject;

Get the frame's f_builtins attribute.

Return a strong reference. The result cannot be nil.

Added in version 3.11.

Public class function GetGenerator(const frame: IPyObject): IPyObject;

Get the generator, coroutine, or async generator that owns this frame, or nil if this frame is not owned by a generator. Does not raise an exception, even if the return value is nil.

Return a strong reference, or nil.

Added in version 3.11.

Public class function GetLasti(const frame: IPyObject): integer;

Returns -1 if frame.f_lasti is None.

Added in version 3.11.

Public class function GetVar(const frame, name_: IPyObject): IPyObject;

Get the variable name_ of frame.

Return a strong reference to the variable value on success.

Raise NameError and return nil if the variable does not exist.

Raise an exception and return nil on error.

name_ type must be a str.

Added in version 3.12.

Public class function GetVarString(const frame: IPyObject; const name_: string): IPyObject;

Similar to TPyFrame.GetVar(), but the variable name_ is a string.

Added in version 3.12.

Public class procedure LocalsToFast(const frame: IPyObject; clear: boolean);

Prior to Python 3.13, this function would copy the f_locals attribute of f to the internal "fast" array of local variables, allowing changes in frame objects to be visible to the interpreter. If clear was true, this function would process variables that were unset in the locals dictionary.

Soft deprecated since version 3.13: This function now does nothing.

Public class function FastToLocalsWithError(const frame: IPyObject): boolean;

Prior to Python 3.13, this function was similar to TPyFrame.FastToLocals(), but would return True on success, and False with an exception set on failure.

Soft deprecated since version 3.13: This function now does nothing.

Public class procedure FastToLocals(const frame: IPyObject);

Prior to Python 3.13, this function would copy the internal "fast" array of local variables (which is used by the interpreter) to the f_locals attribute of f, allowing changes in local variables to be visible to frame objects.

Soft deprecated since version 3.13: This function now does nothing.
