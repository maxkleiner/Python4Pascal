Methods

Public class function Check(const aPyObject: IPyObject): boolean;

Return true if op is an instance of the PyCFunction_Type type or a subtype of it. This function always succeeds.

Public class function CheckExact(const aPyObject: IPyObject): boolean;

This is the same as TPyCFunction.Check(), but does not account for subtypes.

Public class function GetFunction(const func: IPyObject): PyCFunction;

Get the function pointer on func as it was passed to ml_meth.

If func is not a function object, this fails with an exception. func must not be nil.

This function returns the function pointer on success, and nil with an exception set on failure.

Public class function GetSelf(const func: IPyObject): IPyObject;

Get the "self" object on func. This is the object that would be passed to the first argument of a PyCFunction. For function objects created through a PyMethodDef on a PyModuleDef, this is the resulting module object.

If func is not a function object, this fails with an exception. func must not be nil.

This function returns a borrowed reference to the "self" object on success, and nil with an exception set on failure.

Public class function GetFlags(const func: IPyObject): integer;

Get the function's flags on func as they were passed to ml_flags.

If func is not a function object, this fails with an exception. func must not be nil.

This function returns the function's flags on success, and -1 with an exception set on failure.
