Public class function CheckExact(const aPyObject: IPyObject): boolean;

Return true if its argument is a PyCapsule. This function always succeeds.

Public class function New(pointer_: Pointer; const name_: PAnsiChar; destructor_: PyCapsule_Destructor): IPyObject;

Create a PyCapsule encapsulating the pointer. The pointer_ argument may not be nil.

On failure, set an exception and return nil.

The name_ string may either be nil or a pointer to a valid C string. If non-nil, this string must outlive the capsule. (Though it is permitted to free it inside the destructor.)

If the destructor_ argument is not nil, it will be called with the capsule as its argument when it is destroyed.

If this capsule will be stored as an attribute of a module, the name should be specified as modulename.attributename. This will enable other modules to import the capsule using TPyCapsule.Import().

Public class function GetPointer(const capsule: IPyObject; const name_: string): Pointer;

Retrieve the pointer stored in the capsule. On failure, set an exception and return nil.

The name parameter must compare exactly to the name stored in the capsule. If the name stored in the capsule is nil, the name passed in must also be nil. Python uses the C function strcmp() to compare capsule names.

Public class function GetDestructor(const capsule: IPyObject): PyCapsule_Destructor;

Return the current destructor stored in the capsule. On failure, set an exception and return nil.

It is legal for a capsule to have a nil destructor. This makes a nil return code somewhat ambiguous; use TPyCapsule.IsValid() or TPyErr.Occurred() to disambiguate.

Public class function GetName(const capsule: IPyObject): string;

Return the current name stored in the capsule. On failure, set an exception and return nil.

It is legal for a capsule to have a nil name. This makes a nil return code somewhat ambiguous; use TPyCapsule.IsValid() or TPyErr.Occurred() to disambiguate.

Public class function GetContext(const capsule: IPyObject): Pointer;

Return the current context stored in the capsule. On failure, set an exception and return nil.

It is legal for a capsule to have a nil context. This makes a nil return code somewhat ambiguous; use TPyCapsule.IsValid() or TPyErr.Occurred() to disambiguate.

Public class function IsValid(const capsule: IPyObject; const name_: string): boolean;

Determines whether or not capsule is a valid capsule. A valid capsule is non-nil, passes TPyCapsule.CheckExact(), has a non-nil pointer stored in it, and its internal name matches the name parameter. (See TPyCapsule.GetPointer() for information on how capsule names are compared.)

In other words, if TPyCapsule.IsValid() returns a true value, calls to any of the accessors (any function starting with TPyCapsule.Get) are guaranteed to succeed.

Return True if the object is valid and matches the name passed in. Return False otherwise. This function will not fail.

Public class function SetPointer(const capsule: IPyObject; pointer_: Pointer): boolean;

Set the void pointer inside capsule to pointer. The pointer may not be nil.

Return True on success. Return False and set an exception on failure.

Public class function SetDestructor(const capsule: IPyObject; destructor_: PyCapsule_Destructor): boolean;

Set the destructor inside capsule to destructor.

Return True on success. Return False and set an exception on failure.

Public class function SetName(const capsule: IPyObject; const name_: PAnsiChar): boolean;

Set the name inside capsule to name. If non-nil, the name must outlive the capsule. If the previous name stored in the capsule was not nil, no attempt is made to free it.

Return True on success. Return False and set an exception on failure.

Public class function SetContext(const capsule: IPyObject; context: Pointer): boolean;

Set the context pointer inside capsule to context.

Return True on success. Return False and set an exception on failure.

Public class function Import(const name_: string): Pointer;

Import a pointer to a C object from a capsule attribute in a module. The name parameter should specify the full name to the attribute, as in module.attribute. The name stored in the capsule must match this string exactly.

This function splits name on the . character, and imports the first element. It then processes further elements using attribute lookups.

Return the capsule's internal pointer on success. On failure, set an exception and return nil.

Note: If name points to an attribute of some submodule or subpackage, this submodule or subpackage must be previously imported using other means (for example, by using TPyImport.ImportModule()) for the attribute lookups to succeed.
