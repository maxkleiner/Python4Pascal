Public class function AsSecondsDouble(t: PyTime_t): double;

Convert a timestamp to a number of seconds as a double.

The function cannot fail, but note that double has limited accuracy for large values.

Public class function Monotonic(out result_: PyTime_t): boolean;

Read the monotonic clock. See time.monotonic() for important details on this clock.

Public class function PerfCounter(out result_: PyTime_t): boolean;

Public class function Time(out result_: PyTime_t): boolean;
