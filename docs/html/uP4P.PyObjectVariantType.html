Packed Record TPyObjectVarData

Custom TVarData record used by TPyObjectVariantType.

The size of TVarData is 16 bytes on 32-bit (x86) systems and 24 bytes on 64-bit (x64) systems.

The size difference is primarily caused by pointer size changes and stricter data alignment rules on 64-bit architectures.
