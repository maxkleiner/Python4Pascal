Declaration

type TPyStatus = class(TInterfacedObject, IPyStatus)

Description

Class to store an initialization function status: success, error or exit.

For an error, it can store the function name which created the error.

<see href="https://docs.python.org/3/c-api/init_config.html#c.PyStatus">See the article about PyStatus.)

Public procedure ExitStatusException;

Call exit(exitcode) if status is an exit. Print the error message and exit with a non-zero exit code if status is an error. Must only be called if TPyStatus.IsException is true.
