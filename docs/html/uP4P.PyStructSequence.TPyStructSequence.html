Methods

Public class procedure InitType(type_: PPyTypeObject; desc: PPyStructSequence_Desc);

Initializes a struct sequence type type_ from desc in place.

Public class function InitType2(type_: PPyTypeObject; desc: PPyStructSequence_Desc): boolean;

Like TPyStructSequence.InitType(), but returns True on success and False with an exception set on failure.

Public class function NewType(desc: PPyStructSequence_Desc): PPyTypeObject;

Create a new struct sequence type from the data in desc, described below. Instances of the resulting type can be created with TPyStructSequence.New().

Return nil with an exception set on failure.

Public class function New(type_: PPyTypeObject): IPyObject;

Creates an instance of type_, which must have been created with TPyStructSequence.NewType().

Return nil with an exception set on failure.

Public class procedure SetItem(const p: IPyObject; pos: Py_ssize_t; const o: IPyObject);

Sets the field at index pos of the struct sequence p to value o. This should only be used to fill in brand new instances.

Bounds checking is performed as an assertion if Python is built in debug mode or with assertions.

Note This function "steals" a reference to o.

Public class function GetItem(const p: IPyObject; pos: Py_ssize_t): IPyObject;

Return the object at position pos in the struct sequence pointed to by p.

Bounds checking is performed as an assertion if Python is built in debug mode or with assertions.
