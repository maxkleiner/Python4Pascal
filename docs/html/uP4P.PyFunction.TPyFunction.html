Methods

Public class function Check(const aPyObject: IPyObject): boolean;

Return true if aPyObject is a function object (has type PyFunction_Type). The parameter must not be nil. This function always succeeds.

Public class function New(const code, globals: IPyObject): IPyObject;

Return a new function object associated with the code object code. globals must be a dictionary with the global variables accessible to the function.

The function's docstring and name are retrieved from the code object. __module__ is retrieved from globals. The argument defaults, annotations and closure are set to nil. __qualname__ is set to the same value as the code object's co_qualname field.

Public class function NewWithQualName(const code, globals, qualname: IPyObject): IPyObject;

As TPyFunction.New(), but also allows setting the function object's __qualname__ attribute. qualname should be a unicode object or nil; if nil, the __qualname__ attribute is set to the same value as the code object's co_qualname field.

Public class function GetCode(const op: IPyObject): IPyObject;

Return the code object associated with the function object op.

Public class function GetGlobals(const op: IPyObject): IPyObject;

Return the globals dictionary associated with the function object op.

Public class function GetModule(const op: IPyObject): IPyObject;

Return a borrowed reference to the __module__ attribute of the function object op. It can be nil.

This is normally a string containing the module name, but can be set to any other object by Python code.

Public class function GetDefaults(const op: IPyObject): IPyObject;

Return the argument default values of the function object op. This can be a tuple of arguments or nil.

Public class function SetDefaults(const op, defaults: IPyObject): boolean;

Set the argument default values for the function object op. defaults must be Py_None or a tuple.

Raises SystemError and returns False on failure.

Public class procedure SetVectorcall(const func: PyFunctionObject; vectorcall: vectorcallfunc);

Set the vectorcall field of a given function object func.

Warning: extensions using this API must preserve the behavior of the unaltered (default) vectorcall function!

Added in version 3.12.

Public class function GetKwDefaults(const op: IPyObject): IPyObject;

Return the keyword-only argument default values of the function object op. This can be a dictionary of arguments or nil.

Public class function SetKwDefaults(const op, defaults: IPyObject): boolean;

Set the keyword-only argument default values of the function object op. defaults must be a dictionary of keyword-only arguments or Py_None.

This function returns True on success, and returns False with an exception set on failure.

Public class function GetClosure(const op: IPyObject): IPyObject;

Return the closure associated with the function object op. This can be nil or a tuple of cell objects.

Public class function SetClosure(const op, closure: IPyObject): boolean;

Set the closure associated with the function object op. closure must be Py_None or a tuple of cell objects.

Raises SystemError and returns False on failure.

Public class function GetAnnotations(const op: IPyObject): IPyObject;

Return the annotations of the function object op. This can be a mutable dictionary or nil.

Public class function SetAnnotations(const op, annotations: IPyObject): boolean;

Set the annotations for the function object op. annotations must be a dictionary or Py_None.

Raises SystemError and returns False on failure.

Public class function AddWatcher(callback: PyFunction_WatchCallback): integer;

Register callback as a function watcher for the current interpreter. Return an ID which may be passed to TPyFunction.ClearWatcher(). In case of error (e.g. no more watcher IDs available), return -1 and set an exception.

Added in version 3.12.

Public class function ClearWatcher(watcher_id: integer): boolean;

Clear watcher identified by watcher_id previously returned from TPyFunction.AddWatcher() for the current interpreter. Return True on success, or False and set an exception on error (e.g. if the given watcher_id was never registered.)

Added in version 3.12.
