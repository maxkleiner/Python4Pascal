Methods

Public class function Check(const aPyObject: IPyObject): boolean;

Return true if aPyObject is a generator object; aPyObject must not be nil. This function always succeeds.

Public class function CheckExact(const aPyObject: IPyObject): boolean;

Return true if aPyObject's type is PyGen_Type; aPyObject must not be nil. This function always succeeds.

Public class function New(const frame: IPyObject): IPyObject;

Create and return a new generator object based on the frame object. A reference to frame is "stolen" by this function (even on error). The argument must not be nil.

Public class function NewWithQualName(const frame, name_, qualname: IPyObject): IPyObject;

Create and return a new generator object based on the frame object, with __name__ and __qualname__ set to name and qualname. A reference to frame is "stolen" by this function (even on error). The frame argument must not be nil.

Public class function GetCode(const gen: IPyObject): IPyObject;

Return a new strong reference to the code object wrapped by gen. This function always succeeds.
