Methods

Public class function Check(const o: IPyObject): boolean;

Return True if the object provides the mapping protocol or supports slicing, and False otherwise. Note that it returns True for Python classes with a __getitem__() method, since in general it is impossible to determine what type of keys the class supports. This function always succeeds.

Public class function Size(const o: IPyObject): Py_ssize_t;

Returns the number of keys in object o on success, and -1 on failure. This is equivalent to the Python expression len(o).

Public class function Length(const o: IPyObject): Py_ssize_t;

Returns the number of keys in object o on success, and -1 on failure. This is equivalent to the Python expression len(o).

Public class function HasKeyString(const o: IPyObject; const key: string): boolean;

This is the same as TPyMapping.HasKey(), but key is specified as a string, rather than a IPyObject.

Note: Exceptions that occur when this calls the __getitem__() method or while creating the temporary str object are silently ignored. For proper error handling, use TPyMapping.HasKeyStringWithError(), TPyMapping.GetOptionalItemString() or TPyMapping.GetItemString() instead.

Public class function HasKey(const o, key: IPyObject): boolean;

Return True if the mapping object has the key key and False otherwise. This is equivalent to the Python expression key in o. This function always succeeds.

Note: Exceptions which occur when this calls the __getitem__() method are silently ignored. For proper error handling, use TPyMapping.HasKeyWithError(), TPyMapping.GetOptionalItem() or TPyObject.GetItem() instead.

Public class function HasKeyWithError(const o, key: IPyObject): integer;

Return 1 if the mapping object has the key key and 0 otherwise. This is equivalent to the Python expression key in o. On failure, return -1.

Added in version 3.13.

Public class function HasKeyStringWithError(const o: IPyObject; const key: string): integer;

This is the same as TPyMapping.HasKeyWithError(), but key is specified as a string, rather than a IPyObject.

Added in version 3.13.

Public class function Keys(const o: IPyObject): IPyObject;

On success, return a list of the keys in object o. On failure, return nil.

Public class function Values(const o: IPyObject): IPyObject;

On success, return a list of the values in object o. On failure, return nil.

Public class function Items(const o: IPyObject): IPyObject;

On success, return a list of the items in object o, where each item is a tuple containing a key-value pair. On failure, return nil.

Public class function GetItemString(const o: IPyObject; const key: string): IPyObject;

This is the same as TPyObject.GetItem(), but key is specified as a string, rather than a IPyObject.

Public class function GetOptionalItem(const obj, key: IPyObject; out result_: IPyObject): integer;

Variant of TPyObject.GetItem() which doesn't raise KeyError if the key is not found.

If the key is found, return 1 and set result_ to a new strong reference to the corresponding value. If the key is not found, return 0 and set result_ to nil; the KeyError is silenced. If an error other than KeyError is raised, return -1 and set result_ to nil.

Added in version 3.13.
