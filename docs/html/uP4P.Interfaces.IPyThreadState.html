Public procedure Clear;

Reset all information in a thread state object. IPyThreadState.ThreadState must be attached

Changed in version 3.9: This function now calls the PyThreadState.on_delete callback. Previously, that happened in TPyThreadState.Delete().

Changed in version 3.13: The PyThreadState.on_delete callback was removed.

Public procedure Delete;

Destroy a thread state object. IPyThreadState.ThreadState should not be attached to any thread. IPyThreadState.ThreadState must have been reset with a previous call to TPyThreadState.Clear().

Public function SetAsyncExc(id: C_ULong; const exc: IPyObject): integer;

Asynchronously raise an exception in a thread. The id argument is the thread id of the target thread; exc is the exception object to be raised. This function does not steal any references to exc. To prevent naive misuse, you must write your own C extension to call this. Must be called with an attached thread state. Returns the number of thread states modified; this is normally one, but will be zero if the thread id isn't found. If exc is nil, the pending exception (if any) for the thread is cleared. This raises no exceptions.

Changed in version 3.7: The type of the id parameter changed from long to unsigned long.

Public procedure EnterTracing;

Suspend tracing and profiling in the Python thread state IPyThreadState.ThreadState.

Resume them using the TPyThreadState.LeaveTracing() function.

Added in version 3.11.

Public procedure LeaveTracing;

Resume tracing and profiling in the Python thread state IPyThreadState.ThreadState suspended by the TPyThreadState.EnterTracing() function.

See also TPyEval.SetTrace() and TPyEval.SetProfile() functions.

Added in version 3.11.

Public function Swap: IPyThreadState;

Set the attached thread state to IPyThreadState.ThreadState, and return the thread state that was attached prior to calling.

This function is safe to call without an attached thread state; it will simply return nil indicating that there was no prior thread state.

See also TPyEval.ReleaseThread()

Note Similar to TPyGILState.Ensure(), this function will hang the thread if the runtime is finalizing.

Public function Next: IPyThreadState;

Return the next thread state object after IPyThreadState.ThreadState from the list of all such objects belonging to the same PyInterpreterState object.

Public function UnWrap: Pointer;

Return the PyThreadState pointer that was handled by this TPyThreadState instance.

This function must be used when passing a PyThreadState pointer to a function that steals the PyThreadState reference.

Get the unique thread state identifier of the Python thread state tstate.

Public property Dict : IPyObject read GetDict;

Return a dictionary in which extensions can store thread-specific state information. Each extension should use a unique key to use to store state in the dictionary. It is okay to call this function when no thread state is attached. If this function returns nil, no exception has been raised and the caller should assume no thread state is attached.

Public property Interpreter : IPyInterpreterState read GetInterpreter;

Get the interpreter of the Python thread state tstate.

tstate must not be nil, and must be attached.

Public property Frame : IPyObject read GetFrame;

Get the current frame of the Python thread state tstate.

Return a strong reference. Return nil if no frame is currently executing.

See also TPyEval.GetFrame().

tstate must not be nil, and must be attached.

Added in version 3.9.
