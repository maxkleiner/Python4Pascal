Methods

Public class function Check(const aPyObject: IPyObject): boolean;

Return true if o is an instance method object (has type PyInstanceMethod_Type). The parameter must not be nil. This function always succeeds.

Public class function New(const func: IPyObject): IPyObject;

Return a new instance method object, with func being any callable object. func is the function that will be called when the instance method is called.

Public class function Function_(const im: IPyObject): IPyObject;

Return the function object associated with the instance method im.
