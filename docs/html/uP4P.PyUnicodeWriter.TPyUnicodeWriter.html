Protected procedure Discard;

Discard the internal Unicode buffer and destroy the writer instance.

The writer instance is invalid after this call.

Protected function Finish: IPyObject;

Return the final Python str object and destroy the writer instance.

Set an exception and return nil on error.

The writer instance is invalid after this call.

Protected function WriteChar(ch: Py_UCS4): boolean;

Write the single Unicode character ch into writer.

On success, return True. On error, set an exception, leave the writer unchanged, and return False.

Protected function WriteUTF8(const str: PAnsiChar; size_: Py_ssize_t): boolean;

Decode the string str from UTF-8 in strict mode and write the output into writer.

size_ is the string length in bytes. If size is equal to -1, call strlen(str) to get the string length.

On success, return True. On error, set an exception, leave the writer unchanged, and return False.

See also DecodeUTF8Stateful().

Protected function WriteASCII(const str: PAnsiChar; size_: Py_ssize_t): boolean;

Write the ASCII string str into writer.

size_ is the string length in bytes. If size_ is equal to -1, call strlen(str) to get the string length.

str must only contain ASCII characters. The behavior is undefined if str contains non-ASCII characters.

On success, return True. On error, set an exception, leave the writer unchanged, and return False.

Protected function WriteWideChar(const str: PWCharT; size_: Py_ssize_t): boolean;

Write the wide string str into writer.

size_ is a number of wide characters. If size_ is equal to -1, call wcslen(str) to get the string length.

On success, return True. On error, set an exception, leave the writer unchanged, and return False.

Protected function WriteUCS4(const str: PPy_UCS4; size_: Py_ssize_t): boolean;

Writer the UCS4 string str into writer.

size_ is a number of UCS4 characters.

On success, return True. On error, set an exception, leave the writer unchanged, and return False.

Protected function WriteStr(const obj: IPyObject): boolean;

Call TPyObject.Str() on obj and write the output into writer.

On success, return True. On error, set an exception, leave the writer unchanged, and return False.

To write a str subclass which overrides the __str__() method, TPyUnicode.FromObject() can be used to get the original string.

Protected function WriteRepr(const obj: IPyObject): boolean;

Call TPyObject.Repr() on obj and write the output into writer.

If obj is nil, write the string "<NULL>" into writer.

On success, return True. On error, set an exception, leave the writer unchanged, and return False.

Changed in version 3.14.4: Added support for nil.

Protected function WriteSubstring(str: PPyObject; start, end_: Py_ssize_t): boolean;

Write the substring str[start:end] into writer.

str must be Python str object. start must be greater than or equal to 0, and less than or equal to end. end must be less than or equal to str length.

On success, return True. On error, set an exception, leave the writer unchanged, and return False.

Protected function DecodeUTF8Stateful(const string_: PAnsiChar; length: Py_ssize_t; errors: TPyCodecErrors; var consumed: Py_ssize_t): boolean;

Decode string_ from UTF-8 with errors error handler and write the output into writer.

size_ is the string length in bytes. If size_ is equal to -1, call strlen(string_) to get the string length.

errors is an error handler name, such as "replace". If errors is nil, use the strict error handler.

If consumed is not nil, set *consumed to the number of decoded bytes on success. If consumed is nil, treat trailing incomplete UTF-8 byte sequences as an error.

On success, return True. On error, set an exception, leave the writer unchanged, and return False.

See also WriteUTF8().

Public constructor Create(length: Py_ssize_t);
