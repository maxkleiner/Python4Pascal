Methods

Public class function SimpleStringFlags(const command: string; flags: PPyCompilerFlags): boolean;

Executes the Python source code from command in the __main__ module according to the flags argument. If __main__ does not already exist, it is created. Returns True on success or False if an exception was raised. If there was an error, there is no way to get the exception information. For the meaning of flags, see below.

Note that if an otherwise unhandled SystemExit is raised, this function will not return False, but exit the process, as long as PyConfig.inspect is zero.

Public class function AnyFileExFlags(fp: PFILE; const filename: string; closeit: boolean; flags: PPyCompilerFlags): boolean;

If fp refers to a file associated with an interactive device (console or terminal input or Unix pseudo-terminal), return the value of TPyRun.InteractiveLoop(), otherwise return the result of TPyRun.SimpleFile(). filename is decoded from the filesystem encoding (sys.getfilesystemencoding()). If filename is nil, this function uses "???" as the filename. If closeit is true, the file is closed before TPyRun.SimpleFileExFlags() returns.

Public class function SimpleFileExFlags(fp: PFILE; const filename: string; closeit: boolean; flags: PPyCompilerFlags): boolean;

Similar to TPyRun.SimpleStringFlags(), but the Python source code is read from fp instead of an in-memory string. filename should be the name of the file, it is decoded from filesystem encoding and error handler. If closeit is true, the file is closed before TPyRun.SimpleFileExFlags() returns.

Note: On Windows, fp should be opened as binary mode (e.g. fopen(filename, "rb")). Otherwise, Python may not handle script file with LF line ending correctly.

Public class function InteractiveOneFlags(fp: PFILE; const filename: string; flags: PPyCompilerFlags): boolean;

Similar to TPyRun.InteractiveOneObject(), but filename is a string, which is decoded from the filesystem encoding and error handler.

Public class function InteractiveOneObject(fp: PFILE; const filename: IPyObject; flags: PPyCompilerFlags): boolean;

Read and execute a single statement from a file associated with an interactive device according to the flags argument. The user will be prompted using sys.ps1 and sys.ps2. filename must be a Python str object.

Returns True when the input was executed successfully, False if there was an exception, or an error code from the errcode.h include file distributed as part of Python if there was a parse error. (Note that errcode.h is not included by Python.h, so must be included specifically if needed.)

Public class function InteractiveLoopFlags(fp: PFILE; const filename: string; flags: PPyCompilerFlags): boolean;

Read and execute statements from a file associated with an interactive device until EOF is reached. The user will be prompted using sys.ps1 and sys.ps2. filename is decoded from the filesystem encoding and error handler. Returns 0 at EOF or a negative number upon failure.

Public class function StringFlags(const str: string; start: integer; const globals, locals: IPyObject; flags: PPyCompilerFlags): IPyObject;

Execute Python source code from str in the context specified by the objects globals and locals with the compiler flags specified by flags. globals must be a dictionary; locals can be any object that implements the mapping protocol. The parameter start specifies the start symbol and must be one of the available start symbols.

Returns the result of executing the code as a Python object, or nil if an exception was raised.

Public class function FileExFlags(fp: PFILE; const filename: string; start: integer; const globals, locals: IPyObject; closeit: boolean; flags: PPyCompilerFlags): IPyObject;

Similar to TPyRun.StringFlags(), but the Python source code is read from fp instead of an in-memory string. filename should be the name of the file, it is decoded from the filesystem encoding and error handler. If closeit is true, the file is closed before TPyRun.FileExFlags() returns.
