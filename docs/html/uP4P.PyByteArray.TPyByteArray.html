Methods

Public class function Concat(const ob1, ob2: IPyObject): IPyObject;

Concat bytearrays ob1 and ob2 and return a new bytearray with the result.

On failure, return nil with an exception set.

Note: If the object implements the buffer protocol, then the buffer must not be mutated while the bytearray object is being created.

Public class function Size(const ob: IPyObject): Py_ssize_t;

Return the size of bytearray after checking for a nil pointer.

Public class function AsString(const ob: IPyObject): string;

Return the contents of bytearray as a string after checking for a nil pointer.

Note: It is not thread-safe to mutate the bytearray object while using the returned string.

Public class function AsBuffer(const ob: IPyObject): PByte;

Return the contents of bytearray as a PByte after checking for a nil pointer. The returned PByte always has an extra nil byte appended.

Note: It is not thread-safe to mutate the bytearray object while using the returned PByte.

Public class function Resize(const ob: IPyObject; len: Py_ssize_t): boolean;

Resize the internal buffer of bytearray to len. Return False in case of a failure with an exception set.

Changed in version 3.14: A negative len will now result in an exception being set and False returned.

Public class function FromObject(const ob: IPyObject): IPyObject;

Return a new bytearray object from any object, ob, that implements the buffer protocol.

On failure, return nil with an exception set.

Note: If the object implements the buffer protocol, then the buffer must not be mutated while the bytearray object is being created.

Public class function FromString(const str: string): IPyObject;

Create a new bytearray object from a string.

On failure, return nil with an exception set.

Public class function FromStringAndSize(const str: AnsiString; len: Py_ssize_t): IPyObject;

Create a new bytearray object from str and its length, len.

On failure, return nil with an exception set.

Public class function FromBufferAndSize(const buffer: PByte; len: Py_ssize_t): IPyObject;

Create a new bytearray object from buffer and its length, len.

On failure, return nil with an exception set.

Public class function Check(const aPyObject: IPyObject): boolean;

Return true if the object aPyObject is a bytearray object or an instance of a subtype of the bytearray type. This function always succeeds.

Public class function CheckExact(const aPyObject: IPyObject): boolean;

Return true if the object aPyObject is a bytearray object, but not an instance of a subtype of the bytearray type. This function always succeeds.
