type IPyThreadTSS = interface(IInterface)

Description

This interface represents the state of a thread key, the definition of which may depend on the underlying TLS implementation, and it has an internal field representing the key's initialization state.

When Py_LIMITED_API is not defined, static allocation of this type by Py_tss_NEEDS_INIT is allowed.

<see href="https://docs.python.org/3/c-api/tls.html#c.Py_tss_t">See the article about Py_tss_t.)

Public procedure TSSAlloc;

Return a value which is the same state as a value initialized with Py_tss_NEEDS_INIT, or nil in the case of dynamic allocation failure.

Public procedure TSSFree;

Free the given key allocated by TSSAlloc(), after first calling TSSDelete() to ensure any associated thread locals have been unassigned. This is a no-op if the key argument is nil.

Note A freed key becomes a dangling pointer. You should reset the key to nil.

Public function TSSCreate: boolean;

Return True on successful initialization of a TSS key.

The behavior is undefined if the value pointed to by the key argument is not initialized by Py_tss_NEEDS_INIT. This function can be called repeatedly on the same key – calling it on an already initialized key is a no-op and immediately returns success.

Public procedure TSSDelete;

Destroy a TSS key to forget the values associated with the key across all threads, and change the key's initialization state to uninitialized. A destroyed key is able to be initialized again by TSSCreate(). This function can be called repeatedly on the same key – calling it on an already destroyed key is a no-op.
