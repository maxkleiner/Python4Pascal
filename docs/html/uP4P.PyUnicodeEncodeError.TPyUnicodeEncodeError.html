Public class function GetStart(const exc: IPyObject; out start: Py_ssize_t): boolean;

Get the start attribute of the given exception object and place it into *start. start must not be nil. Return True on success, False on failure.

If the UnicodeError.object is an empty sequence, the resulting start is 0. Otherwise, it is clipped to [0, len(object) - 1].

See also UnicodeError.start

Public class function SetStart(const exc: IPyObject; start: Py_ssize_t): boolean;

Set the start attribute of the given exception object to start. Return True on success, False on failure.

Note While passing a negative start does not raise an exception, the corresponding getters will not consider it as a relative offset.

Public class function GetEnd(const exc: IPyObject; out end_: Py_ssize_t): boolean;

Get the end attribute of the given exception object and place it into end_. end must not be nil. Return True on success, False on failure.
