Declaration

type TPyInterpreterState = class(TInterfacedObject, IPyInterpreterState)

Description

This class represents the state shared by a number of cooperating threads. Threads belonging to the same interpreter share their module administration and a few other internal items. There are no public members in this structure.

Threads belonging to different interpreters initially share nothing, except process state like available memory, open file descriptors and such. The global interpreter lock is also shared by all threads, regardless of to which interpreter they belong.

Changed in version 3.12: PEP 684 introduced the possibility of a per-interpreter GIL. See TPy.NewInterpreterFromConfig().

<see href="https://docs.python.org/3/c-api/subinterpreters.html">See the Multiple interpreters in a Python process article.)

Protected procedure Clear;

Reset all information in an interpreter state object. There must be an attached thread state for the interpreter.

Raises an auditing event cpython.PyInterpreterState_Clear with no arguments.

Protected procedure Delete;

Destroy an interpreter state object. There should not be an attached thread state for the target interpreter. The interpreter state must have been reset with a previous call to Clear().

Return the interpreter's unique ID. If there was any error in doing so then -1 is returned and an error is set.

The caller must have an attached thread state.

Added in version 3.7.

Public property Dict : IPyObject read GetDict;

Return a dictionary in which interpreter-specific data may be stored. If this function returns nil then no exception has been raised and the caller should assume no interpreter-specific dict is available.

This is not a replacement for TPyModule.GetState(), which extensions should use to store interpreter-specific state information.

The returned dictionary is borrowed from the interpreter and is valid until interpreter shutdown.

Added in version 3.8.
