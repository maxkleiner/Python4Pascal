type TPyNotImplemented = class(TObject)

Description

The NotImplemented singleton, used to signal that an operation is not implemented for the given type combination. It's immortal since Python 3.12.

<see href="https://docs.python.org/3/c-api/object.html#object-protocol">See the article about the Object Protocol.)
