Public m_index: Py_ssize_t;

The module's index into its interpreter's modules_by_index cache. This is set for all extension modules but only used for legacy ones. (See PyInterpreterState.modules_by_index for more info.) It is set by PyModuleDef_Init().

Public m_copy: PPyObject;

A copy of the module's __dict__ after the first time it was loaded. This is only set/used for legacy modules that do not support multiple initializations. It is set by fix_up_extension() in import.c.
