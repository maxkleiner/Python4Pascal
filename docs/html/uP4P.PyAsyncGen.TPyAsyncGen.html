Public class function CheckExact(const aPyObject: IPyObject): boolean;

Return true if aPyObject is an asynchronous generator object, false otherwise. This function always succeeds.

Public class function New(const frame, name_, qualname: IPyObject): IPyObject;

Create a new asynchronous generator wrapping frame, with __name__ and __qualname__ set to name and qualname. frame is "stolen" by this function (even on error) and must not be nil.

On success, this function returns a strong reference to the new asynchronous generator. On failure, this function returns nil with an exception set.
