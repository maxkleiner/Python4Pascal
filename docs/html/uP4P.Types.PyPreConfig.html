Public _config_init: integer;

_PyConfigInitEnum value

Public parse_argv: integer;

If non-zero, Py_PreInitializeFromArgs() and Py_PreInitializeFromBytesArgs() parse their argv argument the same way the regular Python parses command line arguments: see Command Line Arguments. Default: 1 in Python config, 0 in isolated config.

Public isolated: integer;

Isolated mode: see PyConfig.isolated. Default: 0 in Python mode, 1 in isolated mode.

Public use_environment: integer;

Use environment variables? See PyConfig.use_environment. Default: 1 in Python config and 0 in isolated config.

Public configure_locale: integer;

Set the LC_CTYPE locale to the user preferred locale. If equals to 0, set coerce_c_locale and coerce_c_locale_warn members to 0. See the locale encoding. Default: 1 in Python config, 0 in isolated config.

Public coerce_c_locale: integer;

If equals to 2, coerce the C locale. If equals to 1, read the LC_CTYPE locale to decide if it should be coerced. See the locale encoding. Default: -1 in Python config, 0 in isolated config.

Public coerce_c_locale_warn: integer;

If non-zero, emit a warning if the C locale is coerced. Default: -1 in Python config, 0 in isolated config.

Public legacy_windows_fs_encoding: integer;

If non-zero: - Set PyPreConfig.utf8_mode to 0, - Set PyConfig.filesystem_encoding to "mbcs", - Set PyConfig.filesystem_errors to "replace". Initialized from the PYTHONLEGACYWINDOWSFSENCODING environment variable value. Only available on Windows. Default: 0.

Public utf8_mode: integer;

If non-zero, enable the Python UTF-8 Mode. Set to 0 or 1 by the -X utf8 command line option and the PYTHONUTF8 environment variable. Default: 1.

Public dev_mode: integer;

Python Development Mode: see PyConfig.dev_mode. Default: -1 in Python mode, 0 in isolated mode.

Public allocator: integer;

Name of the Python memory allocator. See PyMemAllocatorName.
