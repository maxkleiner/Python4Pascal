Methods

Public class function CheckExact(const aPyObject: IPyObject): boolean;

Return true if aPyObject is of type PyContext_Type. aPyObject must not be nil. This function always succeeds.

Public class function New(): IPyObject;

Create a new empty context object. Returns nil if an error has occurred.

Public class function Copy(const ctx: IPyObject): IPyObject;

Create a shallow copy of the passed ctx context object. Returns nil if an error has occurred.

Public class function CopyCurrent(): IPyObject;

Create a shallow copy of the current thread context. Returns nil if an error has occurred.

Public class function Enter(const ctx: IPyObject): boolean;

Set ctx as the current context for the current thread. Returns True on success, and False on error.

Public class function Exit(const ctx: IPyObject): boolean;

Deactivate the ctx context and restore the previous context as the current context for the current thread. Returns True on success, and False on error.

Public class function AddWatcher(callback: PyContext_WatchCallback): integer;

Register callback as a context object watcher for the current interpreter. Return an ID which may be passed to TPyContext.ClearWatcher(). In case of error (e.g. no more watcher IDs available), return -1 and set an exception.

Added in version 3.14.

Public class function ClearWatcher(watcher_id: integer): boolean;

Clear watcher identified by watcher_id previously returned from TPyContext.AddWatcher() for the current interpreter. Return True on success, or False and set an exception on error (e.g. if the given watcher_id was never registered.)

Added in version 3.14.
