Public property Metaclass : PPyTypeObject read GetMetaclass write SetMetaclass;

Metaclass is used to construct the resulting type object.

When metaclass is nil, the metaclass is derived from bases (or Py_tp_base[s] slots if bases is nil, see below).

Metaclasses that override tp_new are not supported, except if tp_new is nil.

Public property Module : IPyObject read GetModule write SetModule;

Module can be used to record the module in which the new class is defined. It must be a module object or nil. If not nil, the module is associated with the new type and can later be retrieved with TPyType.GetModule(). The associated module is not inherited by subclasses; it must be specified for each class individually.

Public property Bases : IPyObject read GetBases write SetBases;

Bases can be used to specify base classes; it can either be only one class or a tuple of classes. If bases is nil, the Py_tp_bases slot is used instead. If that also is nil, the Py_tp_base slot is used instead. If that also is nil, the new type derives from object.
