type PyMemberDef = record

Description

Record which describes an attribute of a type which corresponds to a C struct member. When defining a class, put a nil-terminated array of these structures in the tp_members slot.

<see href="https://docs.python.org/3/c-api/structures.html#c.PyMemberDef">See the article about PyMemberDef.)

Description

Fields

Public name: PAnsiChar;

Name of the member. A nil value marks the end of a PyMemberDef[] array. The string should be static, no copy is made of it.

Public type_: integer;

The type of the member in the C struct. See Member types for the possible values.

Public offset: Py_ssize_t;

The offset in bytes that the member is located on the type's object struct.

Public flags: Integer;

Zero or more of the Member flags, combined using bitwise OR.

Public doc: PAnsiChar;

The docstring, or nil. The string should be static, no copy is made of it. Typically, it is defined using PyDoc_STR.
