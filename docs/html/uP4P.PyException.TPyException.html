Methods

Public class function SetTraceback(const ex, tb: IPyObject): boolean;

Set the traceback associated with the exception to tb. Use nil to clear it.

Public class function GetTraceback(const ex: IPyObject): IPyObject;

Return the traceback associated with the exception as a new reference, as accessible from Python through the __traceback__ attribute. If there is no traceback associated, this returns nil.

Public class function GetCause(const ex: IPyObject): IPyObject;

Return the cause (either an exception instance, or None, set by raise ... from ...) associated with the exception as a new reference, as accessible from Python through the __cause__ attribute.

Public class procedure SetCause(const ex, cause: IPyObject);

Set the cause associated with the exception to cause. Use nil to clear it. There is no type check to make sure that cause is either an exception instance or None. This "steals" a reference to cause.

The __suppress_context__ attribute is implicitly set to True by this function.

Public class function GetContext(const ex: IPyObject): IPyObject;

Return the context (another exception instance during whose handling ex was raised) associated with the exception as a new reference, as accessible from Python through the __context__ attribute. If there is no context associated, this returns nil.

Public class procedure SetContext(const ex, ctx: IPyObject);

Set the context associated with the exception to ctx. Use nil to clear it. There is no type check to make sure that ctx is an exception instance. This "steals" a reference to ctx.
