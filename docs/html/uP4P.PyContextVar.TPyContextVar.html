Methods

Public class function CheckExact(const aPyObject: IPyObject): boolean;

Return true if aPyObject is of type PyContextVar_Type. aPyObject must not be nil. This function always succeeds.

Public class function New(const name_: string; const def: IPyObject): IPyObject;

Create a new ContextVar object. The name parameter is used for introspection and debug purposes. The def parameter specifies a default value for the context variable, or nil for no default. If an error has occurred, this function returns nil.

Public class function Get(const var_, default_value: IPyObject; out value: IPyObject): boolean;

Get the value of a context variable. Returns False if an error has occurred during lookup, and True if no error occurred, whether or not a value was found.

If the context variable was found, value will be a pointer to it. If the context variable was not found, value will point to: 

- default_value, if not nil;
- the default value of var, if not nil;
- nil

Except for nil, the function returns a new reference.

Public class function Set_(const var_, value: IPyObject): IPyObject;

Set the value of var to value in the current context. Returns a new token object for this change, or nil if an error has occurred.

Public class function Reset(const var_, token: IPyObject): boolean;

Reset the state of the var context variable to that it was in before TPyContextVar.Set_() that returned the token was called. This function returns True on success and False on error.
