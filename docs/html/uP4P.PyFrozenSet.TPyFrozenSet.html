Public class function Check(const aPyObject: IPyObject): boolean;

Return true if aPyObject is a frozenset object or an instance of a subtype. This function always succeeds.

Public class function CheckExact(const aPyObject: IPyObject): boolean;

Return true if aPyObject is a frozenset object but not an instance of a subtype. This function always succeeds.

Public class function New(const iterable: IPyObject): IPyObject;

Return a new frozenset containing objects returned by the iterable. The iterable may be nil to create a new empty frozenset. Return the new set on success or nil on failure. Raise TypeError if iterable is not actually iterable.

Note: The operation is atomic on free threading when iterable is a set, frozenset, dict or frozendict.
