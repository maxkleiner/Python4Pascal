type PyLongExport = record

Description

Export of a Python int object. There are two cases: If digits is nil, only use the value member. If digits is not nil, use negative, ndigits and digits members.

<see href="https://docs.python.org/3/c-api/long.html#c.PyLongExport">See the article about PyLongExport.)
